# Markdown 阅读器（纯 HTML 单文件版）

一个无需安装、打开即用的本地 Markdown 阅读与编辑工具。所有功能都封装在一个 HTML 文件中，支持打开本地文件或文件夹、树形目录浏览、实时预览、编辑保存、导出 Word，并能正确解析本地相对路径图片。

---

## ✨ 功能特性

### 📂 文件与文件夹管理
- **打开本地文件**：通过文件选择器打开单个 `.md` / `.markdown` / `.txt` 等文件。
- **打开本地文件夹**：递归扫描文件夹，在左侧树形展示所有 Markdown 文件及子文件夹。
- **拖拽打开**：直接把 Markdown 文件或整个文件夹拖入页面即可打开。
- **文件树导航**：点击左侧任意文件，右侧立即预览；当前文件高亮显示。

### 👁️ 预览与阅读
- **Markdown 实时渲染**：支持标题、列表、表格、引用、代码块、链接、图片、分隔线等常用语法。
- **本地图片解析**：自动识别相对路径图片（如 `images/整体架构图.jpg`），从本地读取并内嵌显示，同时兼容 base64 和网络图片。
- **图片失败降级**：图片无法加载时显示友好占位提示，而不是空白或破损图标。
- **目录导航（预览模式）**：点击右上角「目录」，右侧滑出文档大纲，点击标题平滑滚动到对应位置。

### ✏️ 编辑与保存
- **编辑模式**：点击「编辑」进入纯文本编辑，支持实时字数统计。
- **编辑模式目录**：编辑时同样可以打开目录，点击标题直接跳转到编辑区对应位置，方便快速定位章节。
- **保存文件**：支持 File System Access API 的浏览器可直接写回原文件；否则下载修改后的副本。
- **取消编辑**：一键放弃修改，返回预览模式。

### 📤 导出 Word
- **一键导出**：将当前文档转为 Word 格式（`.doc`），保留标题、表格、代码块、引用等样式。
- **图片内嵌**：本地图片会转为 DataURL 一并写入 Word 文档，确保图片正常显示。

### 🧩 界面与交互
- **可拖拽分隔条**：鼠标拖动左侧文件树与右侧预览区之间的分隔条，自由调整侧边栏宽度。
- **双击恢复默认**：双击分隔条快速恢复默认宽度。
- **收起 / 展开侧边栏**：点击侧边栏右上角按钮收起文件树，全宽显示预览；收起后预览区左上角出现展开按钮，一键还原。
- **宽度记忆**：侧边栏宽度自动保存到本地，下次打开保持习惯尺寸。
- **响应式布局**：小屏幕下侧边栏自动变为浮层，避免遮挡内容。

### ⌨️ 快捷键
| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + B` | 收起 / 展开侧边栏 |
| `Ctrl + S` | 编辑模式下保存文件 |
| `Ctrl + Enter` | 导出 Word |
| `Esc` | 取消编辑 |

## 🛠️ 技术实现

### 整体架构
- **纯前端单文件**：HTML + CSS + JavaScript，零依赖、零构建，双击即可在浏览器中运行。
- **模块化组织**：代码按功能划分为 Markdown 解析器、状态管理、文件树、图片解析、编辑保存、导出等模块。

### 核心技术点

#### 1. 自研轻量级 Markdown 解析器
- 支持块级语法：标题、围栏代码块、引用、表格、有序 / 无序列表（含嵌套）、分隔线、段落。
- 支持行内语法：加粗、斜体、删除线、行内代码、链接、图片。
- 图片标签预处理：修复跨行 `<img>`、中文引号、`base64` 路径等常见错误。
- 使用占位符机制避免行内代码和原始 HTML 被错误转义。

#### 2. 本地文件系统访问
- **File System Access API**：`showOpenFilePicker()`、`showDirectoryPicker()` 获取文件 / 目录句柄，支持直接写回原文件。
- **兜底方案**：`<input type="file">` 和 `<input webkitdirectory>` 兼容不支持上述 API 的浏览器。
- **递归目录遍历**：通过 `for await...of` 遍历目录句柄，构建树形结构，自动跳过 `node_modules`、`.git` 等目录。

#### 3. 本地图片解析
- 以当前 Markdown 文件所在目录为基准，解析 `./`、`../` 等相对路径。
- 两种数据来源：
  - File System Access API：从根目录句柄逐级查找并读取图片文件。
  - `webkitdirectory` / 拖拽：通过 `webkitRelativePath` 构建「相对路径 → File」映射表。
- 图片转为 DataURL 后缓存到内存，避免重复读取；切换文件夹时自动清空缓存。

#### 4. 可拖拽分隔条
- 基于 Pointer Events（`pointerdown` / `pointermove` / `pointerup`）实现，支持鼠标和触摸。
- 使用 `setPointerCapture` 确保拖动过程不丢失焦点。
- 宽度限制在 `180px` ~ 窗口宽度的 `70%` 之间，并持久化到 `localStorage`。

#### 5. 导出 Word
- 将渲染后的 HTML 包装为带命名空间的 Word 兼容 HTML，通过 `Blob` 下载为 `.doc` 文件。
- 图片在预览模式下已是 DataURL，导出时直接内嵌，无需额外处理。

#### 6. 性能与体验优化
- **防抖渲染**：编辑输入停止 150ms 后才重新渲染预览。
- **防抖目录更新**：编辑模式下目录面板每 500ms 防抖重建，并保持滚动位置。
- **渲染令牌**：异步图片解析时使用 `renderToken` 防止旧结果覆盖新文件。
- **事件委托**：文件树点击通过统一事件处理，减少事件监听器数量。

## 🚀 快速开始

1. 下载 `markdown-reader.html` 文件。
2. 双击用浏览器打开（推荐 Chrome / Edge）。
3. 点击「打开文件」选择单个 Markdown 文件，或点击「打开文件夹」浏览整个目录。
4. 也可以直接把文件或文件夹拖入页面。

---

## 📝 使用技巧

- **长文件名显示不全**：拖动左侧分隔条加宽侧边栏即可。
- **专注预览**：按 `Ctrl + B` 收起侧边栏，全宽阅读。
- **快速定位章节**：预览或编辑时打开「目录」，点击标题跳转。
- **批量查看文档**：直接拖入整个文件夹，左侧树形浏览所有 Markdown 文件。
- **图片路径**：文档中的图片建议使用相对路径（如 `images/xxx.jpg`），打开文件夹后即可正常显示。
